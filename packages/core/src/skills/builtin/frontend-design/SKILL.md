# frontend-design

Use when creating a new UI or reshaping an existing one.

1. Confirm the surface: new screen or change to an existing layout.
2. Choose one aesthetic direction first (type, color, motion). State it in a sentence.
3. Avoid generic defaults: Inter, purple gradients, and identical card grids.
4. Implement the UI to match that direction. Keep structure and spacing intentional.
5. Check contrast, hierarchy, and that the look is coherent end to end.
