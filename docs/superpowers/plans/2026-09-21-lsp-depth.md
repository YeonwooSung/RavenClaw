### Plan rulings (amend the spec where they disagree)

The spec stays the product authority. These lines resolve underspecification only.

1. **Same tool.** `LspOperation` / schema enum += `implementation`, `typeDefinition`, `diagnostic`. Description string updates in place. `line` stays required (0-based). Diagnostic **ignores** `line` / `character` (`line: 0` is valid). Do not fork parse. Do not add `scope` / `includeWarnings` / `format`.

2. **Split `query` roots.** `loadLspConfig(configCwd)`. Spawn / `rootUri` / `workspaceFolders` / `resolveInWorkspace` / session key from `workspaceCwd`. Signature: `query(req, cwdOrRoots: string | { workspaceCwd: string; configCwd: string })`. A string means both roots equal that cwd (keeps existing tests). `createLspTool` `execute` passes `{ workspaceCwd: ctx.turn.cwd, configCwd: ctx.turn.projectCwd ?? ctx.turn.cwd }`. `isEnabled` stays `loadLspConfig(ctx.turn.projectCwd ?? ctx.turn.cwd) != null`. This split applies to hover / definition / references too.

3. **Store `ServerCapabilities`.** Explicit `false` on the matching provider → `LSP failed: server does not support {operation}` without sending that method (`didOpen` / `didChange` may still run). Absent / `true` / object → still try. **Diagnostic is not this refuse path:** `diagnosticProvider` present (`true` or object) → pull `textDocument/diagnostic`; `false` or absent → drain the `publishDiagnostics` buffer.

4. **Reverse-RPC this door.** `workspace/workspaceFolders` → the folders we advertised. `workspace/configuration` → one `{}` per `params.items` entry (`[]` if `items` missing). `window/workDoneProgress/create` → `null`. `workspace/applyEdit` → `{ applied: false }` (do not write files). Unknown server requests stay `{ result: null }`.

5. **Diagnostics buffer + formatter.** Last `publishDiagnostics` per URI, store at most 20 items. Compact lines `path:line:col severity code message` using `req.path` and 0-based `range.start` (matches the tool’s `line`). Severity names `error` / `warning` / `information` / `hint`; missing severity sorts as error. `code` omitted when absent; `{ value }` uses `value`. Sort errors before warnings before information before hint, take 20, then the existing 8k clip (`... [truncated]`). Empty → `""`. Position ops stay pretty-printed JSON + 8k clip.

6. **Frame cap 256 KiB in `lsp/client.ts` `onData` only.** Local header scan (do **not** add `max` to `consumeJsonRpcFrames`). If `Content-Length` > `256 * 1024`, skip that frame without `JSON.parse`. Incomplete oversized bodies: remember remaining bytes to skip so the buffer cannot grow without bound. MCP `consumeJsonRpcFrames` stays uncapped. Test: LSP drops oversized (invalid JSON body must not kill the session); MCP parser still accepts a frame larger than 256 KiB.

7. **Timeouts.** Initialize **30s**; query **8s**; diagnostic drain wait ≤ **1.5s** (drain **is** the query, not stacked on 8s). Distinct strings: `LSP failed: timed out` vs `LSP failed: language server not available`. Spawn ENOENT / missing stdio / crash → not available. ```ts
function fakeLspChild(
  results: Partial<Record<string, unknown>> = {},
  opts?: { silent?: ReadonlySet<string>; publishOnOpen?: unknown[] },
): {
  child: LspChild
  methods: string[]
  params: unknown[]
  replies: Array<{ id: unknown; result: unknown }>
  starts: Array<{ command: string; args: string[]; cwd: string }>
  killed: boolean
  exit: () => void
  emitRequest: (method: string, id: number, params: unknown) => void
  pushRaw: (chunk: Buffer) => void
} {
  const stdout = new EventEmitter()
  const methods: string[] = []
  const params: unknown[] = []
  const replies: Array<{ id: unknown; result: unknown }> = []
  const state = { killed: false }
  let buffer = Buffer.alloc(0)
  const silent = opts?.silent ?? new Set<string>()
  const child: LspChild = {
    stdin: {
      write(chunk: string | Uint8Array) {
        const incoming = typeof chunk === 'string' ? Buffer.from(chunk, 'utf8') : chunk
        buffer = Buffer.concat([buffer, incoming])
        const parsed = consumeJsonRpcFrames(buffer)
        buffer = parsed.rest
        for (const message of parsed.messages) {
          if (!message || typeof message !== 'object') continue
          const rec = message as { id?: unknown; method?: unknown; params?: unknown; result?: unknown }
          if (typeof rec.method !== 'string') {
            if (rec.id !== undefined) replies.push({ id: rec.id, result: rec.result })
            continue
          }
          methods.push(rec.method)
          params.push(rec.params)
          if (rec.method === 'textDocument/didOpen' && opts?.publishOnOpen) {
            const uri = (rec.params as { textDocument?: { uri?: string } } | undefined)?.textDocument
              ?.uri
            if (uri) {
              queueMicrotask(() => {
                stdout.emit(
                  'data',
                  encodeJsonRpcFrame({
                    jsonrpc: '2.0',
                    method: 'textDocument/publishDiagnostics',
                    params: { uri, diagnostics: opts.publishOnOpen },
                  }),
                )
              })
            }
          }
          if (rec.id === undefined) continue
          if (silent.has(rec.method)) continue
          const short = rec.method.split('/').at(-1) ?? rec.method
          const result =
            rec.method === 'initialize'
              ? (results.initialize ?? {
                  capabilities: {
                    hoverProvider: true,
                    definitionProvider: true,
                    referencesProvider: true,
                  },
                })
              : (results[short] ?? results[rec.method] ?? null)
          queueMicrotask(() => {
            stdout.emit('data', encodeJsonRpcFrame({ jsonrpc: '2.0', id: rec.id, result }))
          })
        }
        return true
      },
      end() {},
    },
    stdout,
    kill() {
      state.killed = true
      return true
    },
    on(event, listener) {
      stdout.on(event, listener)
      return this
    },
    off(event, listener) {
      stdout.off(event, listener)
      return this
    },
  }
  return {
    child,
    methods,
    params,
    replies,
    starts: [],
    get killed() {
      return state.killed
    },
    exit() {
      stdout.emit('exit', 1)
    },
    emitRequest(method, id, params) {
      stdout.emit('data', encodeJsonRpcFrame({ jsonrpc: '2.0', id, method, params }))
    },
    pushRaw(chunk) {
      stdout.emit('data', chunk)
    },
  }
}
